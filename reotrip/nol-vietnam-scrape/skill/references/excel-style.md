# 交付 Excel

给中国人看。表头、工作表名、文件名用中文。韩文只留在「（韩）」对照列的单元格里。

文件名：`NOL_越南单门票纯接送.xlsx`

字段骨架对齐参考表 `vietnam_tickets_transfers.xlsx`（原 RU 列改为「（韩）」）。

## 工作表

1. 产品对照
2. 套餐对照
3. 流量与订单
4. 字段说明

NOL 没有的列留空：已下单人数、热度、组织者订单数/接待/已付款/组织者评分。

映射要点：

- 分类 / 格式（中）：单门票 或 纯接送
- 成团类型（中）：单门票→自行入园（单门票）；包车→包车；班车/拼车→拼车/班车
- 出行方式（中）：单门票→自行前往；接送→车辆
- 计价单位（中）：每人 或 每车
- 价格展示（韩）：`{售价}원/인` 或 `{售价}원/대`
- 链接：`https://tour.yanolja.com/tna/products/{id}`
- 前端口径：`NOL未公开 / 前端未展示下单人数`

## 套餐对照（18 列）

分类, 产品ID, 产品标题（韩）, 产品标题（中）, 套餐ID, 套餐名（韩）, 套餐名（中）, 套餐说明（韩）, 套餐说明（中）, 计价类型（韩）, 计价类型（中）, 价格, 货币, 展示（韩）, 单位（韩）, 最少数量, 最多数量, 提前截止(小时)

一行一个选项。套餐名 = `套餐 / 选项`（选项与套餐同名则只写一层）。

- 门票票种：`per_person_price` / 按人计价，单位 `/인`
- 接送车型或按车：`per_group_price` / 按车计价，单位 `/대`
- 无选项时按套餐价写一行
