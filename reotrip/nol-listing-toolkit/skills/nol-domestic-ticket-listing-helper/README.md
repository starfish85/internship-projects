# nol-domestic-ticket-listing-helper

NOL **中国国内景区 / 主题公园门票** 上架辅助 Skill（Grok）。

面向合作后台 `tour.triple.partners` 的门票类商品：韩文客户文案、场次/年龄票种、入园与预约规则、售价与选项管理，以及安全停手边界（不点批准）。

> 接送 / 包车类产品请用同级目录的 [`nol-product-listing-helper`](../nol-product-listing-helper/)。

## 适用场景

- 国内景区门票、主题公园 1 日票、通票 / 凭证类商品
- Excel 表 `国内景区门票` 批量上架
- 用户问「怎么填 / 继续上架 / 售价怎么写 / 护照入园怎么写」

## 不适用范围

- 私人包车、机场/港口/景点接送 → 用 `nol-product-listing-helper`
- 港迪等 Excel 明确「平台有官方合作、不给上」的行 → 不创建草稿

## 产品族（上架前先分类）

| 族 | 典型产品 | 选项 | 票种 | 入园方式要点 |
| --- | --- | --- | --- | --- |
| **A 场次景区** | 豫园、恭王府、雍和宫、天坛等 | 上午 / 下午两场 | **仅成人** | 邮件电子票/入园通知；预约收姓名+护照 |
| **B 护照入园** | 上迪、北环 1 日票 | 单选项 `1일 입장권` | 成人+儿童 | **不预先发电子/纸质票**；当日护照识别入园；儿童不可单卖 |
| **C 电子票主题公园** | 港迪（仅允许上架时） | 1 日票 | 成人+儿童 | 邮件电子票；入园一般不强制护照字段 |
| **D 不上架** | Excel 写「不给上」 | — | — | 停止，不建草稿 |

详细矩阵、韩文模板、预约字段见 [`SKILL.md`](./SKILL.md)。

## 售价规则（硬 · 2026-08-11 升格）

- **只填 Excel「售价hkd」列求值结果**，**禁止** 把「加价逻辑」列（成本/基数）当客户价  
- 售价列若为公式（如 `=D/0.8`）→ **必须求值后**再写 NOL（黄浦江：加价逻辑 152.33 → 售价 **190**，勿写 152.33）  
- 「禁止默认 /0.8」= 无售价公式、无用户公式时 **禁止自创** 除法；**不禁止** 执行表内已有售价公式  
- 动手前汇报：`【售价来源】售价hkd=…（加价逻辑=…未用）`  
- 有「加价逻辑 + 售价」两列时，客户价永远取 **售价hkd**

## 安全边界

- **禁止**点击 `批准請求` / `提交審核` / `승인요청` 等提交审核控件
- 默认在 **选项管理（選項管理）** 卡片齐全后停手
- 不主动点页级黑色 `臨時存儲`，除非用户当轮明确要求临时保存
- 操作指引用中文；客户可见字段一律用**可粘贴韩文**
- **文字定位 + 真选中验收：** 任意点击必须以 **DOM 读回** 为完成条件；无验收字段禁止下一步、禁止说「已选中」。分类表：属性/私人的(若出现)、预约、时钟分钟、时段/场次、假日。详见 `SKILL.md` → Absolute Safety Stops / 优先级卡点 / 真选中验收表
- **Live 运行节奏（硬）：** ① 单 CDP、先杀残留 ② 短步+每步验收，禁 silent 长跑 ③ 视口不压窄（≥1440 或沿用用户窗） ④ 脚本 timeout + FAIL exit≠0 ⑤ **>N 分钟无中文汇报 → 中断拆步重来**（默认 N=2）。详见 `SKILL.md` → Live 运行节奏专节
- **定点修补 · 禁整页刷新重填（硬，2026-08-11）：** 单字段/单步 FAIL → 只修缺项 + DOM 读回；禁止 `reload`/整页重开属性·介绍；已填（主题/POI/图/文案/预约/价）是资产；`保存然后` 灰 → 枚举红字逐项补；仅白屏/掉登录/用户明确要求可整页重载。与先保存再退出、逐步验收并列
- **成功必须沉淀 / 下次必须复用（硬，2026-08-11）：** PASS → 同轮写入 `SKILL.md`「已验证路径」或 `lib` 唯一实现；未写入禁止说可复用；新产品动手前声明复用入口；失败改唯一实现再跑，禁 silent 重试/即兴第二套；**价/名/图跟当单 Excel**，只复用流程。与接送 §40 时段 / §56 POI / §55 逐步验收并列

## 主数据源

- Excel：`NOL 待上架产品.xlsx` / `NOL 待上架产品 (1).xlsx`
- Sheet：**`国内景区门票`**
- 优先级：用户当批 Excel > 供应链页/截图 > Skill 内旧示例

## 与上架流程的关系

1. 读 Excel 行 → 判定 Family A/B/C/D  
2. 核对供应链（票种、入园方式、库存说明）  
3. 按族写韩文案 + 统一售卖设置  
4. 属性 → 介绍 → 法规 → 选项  
5. 选项管理可见后 **停止**，交给人工审核/批准
