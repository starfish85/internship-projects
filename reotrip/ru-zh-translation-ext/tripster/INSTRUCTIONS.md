# 怎么给我下 Tripster 指令

仓库里有两套插件。只说「那个俄语插件」会改错项目。

## 复制这段开头

```
改 Tripster 插件（只动 tripster/，不要动根目录 Sputnik8）：
```

后面按需贴下面几类。一条一事，带原文和 URL。

## 1. 漏翻（含下拉、点开才出现的）

```
漏翻：
- URL: https://experience.tripster.ru/experience/28371/
- 操作: 点「筛选」→「形式」
- 原文: <俄语>
- 建议中文: <你要的说法，没有就写「按运营口吻」>
```

## 2. 机翻腔 / 译反

```
修译文：
- URL: ...
- 现在: 作者游览 / 个体游览 / 进行预订
- 应改成: 向导自制行程 / 包团 / 预订
- 若是固定栏，请写进词典，不要只靠机翻
```

## 3. 批量加词

```
加进 tripster 词典（exact，除非我写明 phrase）：
- "Бесплатная отмена за 48 часов" → 出发前 48 小时可免费取消  [product]
- "за человека" → 每人  [price]
```

## 4. 新页面类型

```
Tripster 新覆盖：
- 页面类型: 多日游详情 / 订单支付 / 收藏夹
- URL: ...
- 先抽固定栏进词典，长介绍可以继续机翻
```

## 不要这样写

- 「按上次那个再做一遍」——上次是 Sputnik8
- 只丢一个首页链接，不说要改词典还是修引擎
- 让我改根目录 `extension/` 来适配 Tripster
