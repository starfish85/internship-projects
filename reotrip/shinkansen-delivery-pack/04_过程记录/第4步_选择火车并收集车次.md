# 第 4 步：选择火车并收集车次

目标：在 Trip.com 页面里切到“火车”结果，忽略巴士，只保留符合时间条件的车次。

当前脚本：

```text
03_实习生提交/shinkansen-price-skill/scripts/collect_tripcom_results.py
```

筛选规则：

- 只保留包含 `新干线`、`Shinkansen`、`Nozomi` 或 `Hikari` 的结果块。
- 自动排除 `巴士` / `Bus`。
- 如果用户给的是具体时间，则默认保留距离目标时间 90 分钟以内的车次。
- 如果用户只给了时间段词，例如 `上午`，则按时间段窗口过滤。

使用示例：

```text
python scripts/collect_tripcom_results.py --text "新干线 | Nozomi No.230 ..."
```
