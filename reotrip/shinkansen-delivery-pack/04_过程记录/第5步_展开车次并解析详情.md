# 第 5 步：展开车次并解析详情

目标：对符合条件的车次逐个展开后，提取座席类型、价格和附加说明。

当前脚本：

```text
03_实习生提交/shinkansen-price-skill/scripts/parse_tripcom_details.py
```

可解析内容：

- 车次名称，例如 `Nozomi No.230`
- 出发时间和到达时间
- 出发站和到达站
- 行程时长
- 车次总价
- 座席类型列表
- 每个座席类型对应的价格（如果页面文本中有展示）
- 座席附加说明，例如 `座位保證`、`自由座位`、`電源插座`

使用示例：

```text
python scripts/parse_tripcom_details.py --text "展开后的车次文本..."
```

如果只想看某个时间段的车次，可以加：

```text
python scripts/parse_tripcom_details.py --text "展开后的车次文本..." --preferred-time 上午
```
