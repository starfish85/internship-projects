# 第 3 步：日期和时间选择

目标：在 Trip.com 页面中，按提取到的字段继续选择日期和出发时间。

当前脚本：

```text
03_实习生提交/shinkansen-price-skill/scripts/plan_tripcom_selection.py
```

选择规则：

- 日期直接使用提取出的目标日期。
- 如果有具体时间，直接使用具体时间。
- 如果只有“上午 / 下午 / 中午 / 早上 / 晚上”这类时间段，则转换成页面选择时刻：
  - 凌晨 -> 06:00
  - 早上 -> 08:00
  - 上午 -> 08:00
  - 中午 -> 12:00
  - 下午 -> 15:00
  - 晚上 -> 18:00

使用示例：

```text
python scripts/plan_tripcom_selection.py "客人 2 位成人，想从新大阪到东京，日期是 2026 年 7 月 18 日，尽量查上午出发的车次。"
```

输出会包含：

- 出发地
- 终点
- 日期
- 时间
- 对应 Trip.com 查询链接
