# 项目结构说明

本项目按“源材料、参考资料、最终交付、过程记录”分区存放，避免任务材料、测试材料和交付文件混放。

## 目录结构

```text
arrange schedule skill/
├─ 01_任务说明/
│  └─ 新干线车票价格查询Skill任务说明.md
├─ 02_参考资料/
│  ├─ 参考链接.md
│  ├─ 测试样例.md
│  └─ 截图样例/
├─ 03_实习生提交/
│  └─ shinkansen-price-skill/
│     ├─ SKILL.md
│     ├─ README.md
│     ├─ examples/
│     │  ├─ sample-inputs.md
│     │  └─ sample-output.md
│     ├─ agents/
│     │  └─ openai.yaml
│     ├─ 测试记录.md
│     └─ 交付说明.md
└─ 04_过程记录/
```

## 存储规则

- `01_任务说明/`：只存放任务原始说明和验收要求，不在这里写交付内容。
- `02_参考资料/`：只存放参考链接、测试样例、截图样例等输入材料。
- `02_参考资料/截图样例/`：后续若添加截图测试素材，统一放在这里。
- `03_实习生提交/`：只存放最终要提交的文件和 Skill 项目。
- `03_实习生提交/shinkansen-price-skill/`：Skill 的正式项目目录。
- `examples/`：只存放样例输入和样例输出，不存真实批量查价结果。
- `agents/`：只存放 Codex Skill 的 UI/调用元数据。
- `04_过程记录/`：存放过程笔记、架构说明、临时决策记录；不作为最终交付主体。

## 后续新增文件约定

- 如果补充浏览器自动化脚本，放入 `03_实习生提交/shinkansen-price-skill/scripts/`。
- 如果补充 HTML 展示页，放入 `03_实习生提交/shinkansen-price-skill/`，并在 README 中说明。
- 如果补充真实查询截图或测试截图，放入 `02_参考资料/截图样例/`，不要放入交付目录。
- 如果补充测试总结，只更新 `03_实习生提交/shinkansen-price-skill/测试记录.md`。
