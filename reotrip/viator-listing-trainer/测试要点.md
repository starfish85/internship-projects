## 必测：这一包相对上一包改了什么

### 1. Creation Type / Smart Creator / 标题

- **Creation Type**：两大条单选，带说明。本样例勾 **Manual Creation**
- **Smart Creator**：Select your tone = Expert；Paste URL 旁有 RECOMMENDED；下面是 URL 框、Generate / Skip（都点不了）
- **Language and title**：语言是下拉 English；翻译是单选，勾 **Use automated translation (recommended)**；参考码是「Add your product reference code (optional)」链接，不是空输入框

### 2. Categorization 是大卡片，不是下拉

- 五个类型：Tour / Activity / Ticket or pass / Rental / Transport，每条有英文说明
- **Ticket or pass** 勾上，并展开「What type(s) of ticket/pass is it?」
- 标签是 **Theme Park**、**Cultural**（不要再找 Itinerary type 下拉；向导里没有这一条）

### 3. Photos / 门票详情 / 讲解语言

- **Photos**：Gallery 2/50、第一张 Cover、Drag & drop
- **Ticket details**：多景点 Yes/No；地点卡带东迪地址；时长是 Set duration + hours，另有 Flexible duration
- **Languages Offered**：只有一句「Do you offer in-person, audio or written guides?」，勾 No；不要再出现三条导游语言

### 4. 取消政策和提交页

- **Cancellation policy**：Standard 带 RECOMMENDED；本产品勾 **All sales final**
- Bad weather / Not enough travelers 仍是空勾 + 灰字 **无需勾选**
- **Submit for review**：能看到 Product Submission Fee $29.00；**Submit** 和 **Save as draft** 都点不了

## 顺带回归（上一包已有，抽查即可）

| 测什么 | 怎么过 |
| --- | --- |
| 强制引导 | 清空数据后必须从第 1 条走，左侧未读步骤点不了 |
| 点左侧步骤 | 通关后点 Ticket redemption / Submit，右边从该步顶部开始 |
