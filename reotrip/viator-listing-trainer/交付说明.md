1. 这个项目实现了什么功能：只读的 Viator 草稿上架向导。界面按 5514894P513 真页只读对照：产品类型是大卡片（Ticket or pass + Theme Park / Cultural），Smart Creator 是语气 + Paste URL + Generate/Skip，标题页是语言下拉和翻译单选。第一次打开强制聚光灯引导；通关后可点步骤和字段「?」。问号四段：此处填什么、建议文案格式、换产品时看什么、常见错法。通关后可搜字段；顶栏可切中/EN 界面。例句来自 5514894P11 / 草稿 P513，不是下一份门票的标准答案。
2. 这个项目怎么使用，输入是什么或怎么打开：双击打开 `index.html`。引导中点 Next / 上一项，或键盘 Enter、← →。下拉或引导卡挡住字段时，可在右边滚动把内容滑开。点左侧步骤后，右边从该步顶部开始。通关后用顶栏搜索字段、点「?」。重置：点「重新走新手引导」或清掉 localStorage 键 `viator-training-v2`。测试重点见 `测试要点.md`。
3. 还有什么未实现：阅读/可填写切换（现固定只读）；接送/包车产品切换；引导旁白全文英译。训练页不做成 Manage Tab。真实后台禁止点 Save / Submit / Clone / Improve。
