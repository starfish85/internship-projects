# Viator 上架训练页 · 阶段 B（只读仿真向导）

本地、只读的 Viator **草稿制作器**训练副本。样例是东京迪士尼门票 `5514894P11`（可选地铁通票），草稿对照 `5514894P513`。

界面按 2026-08-26 草稿向导只读抓取：产品类型大卡片、Smart Creator、标题页翻译单选。指引文案仍以 Manage P11 为准。

## 怎么打开

唯一入口：

```text
index.html
```

用 Chrome / Edge / Safari **直接打开**（双击即可）。数据已经打进 `js/data.js`，不需要本地服务器，也不需要联网才能看步骤和文案。

照片来自 Tripadvisor 公开图床，没有网时图片会空，字段和步骤不受影响。

第一次打开若还停在旧引导，可点顶栏「重新走新手引导」，或清掉本页 `localStorage` 键 `viator-training-v2` 再刷新。通关后同一顶栏可搜索字段、切换中/EN。

给实习生的抽测清单见同目录 `测试要点.md`。

## 这个页面做什么

- 左侧 22 个草稿向导步骤，中间当前步，底部 Previous / Next
- 第一次打开强制走新手引导（聚光灯）。每张卡片两段：**此处填什么信息**、**建议文案格式**
- 下拉字段默认展开选项列表；点当前值那一行可收起
- 全部读完后解锁：自由点左侧步骤；点「?」看填什么、格式、**换产品时看什么**、常见错法
- 通关后顶栏可搜索字段；可切换中/EN 界面（字段名始终英文）
- 引导中可用键盘 Enter / → 前进，← 后退
- 东迪现网填值只当例句。换产品按供应链重写，不要整页照抄
- 提交审核按钮看得到，点不了
- 刷新后停留在上次步骤和引导进度

## 明确还没做

- 阅读版 / 可填写版切换（现在固定只读）
- 接送 / 包车产品切换
- 训练页外壳仍是草稿向导，不是已上线 Manage 的 Tab 界面

## 改数据

改 `data/` 里的 JSON，然后重新生成 `js/data.js`：

```text
python3 scripts/build-data.py
```

不要改材料包原件。本项目只使用 `data/` 副本。

## 技术

Vanilla HTML + CSS + JS。无后端、无登录、不连 Viator 接口。

代码里预留了 `getStepsForProductType()` 和 `APP_MODE = "readonly"`，方便以后的可填写模式。
