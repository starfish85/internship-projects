# 哪些要运营补内容标准

范围：训练页左边 22 步、60 格。产品线先按**门票**（不是接送、不是包车）。

同事只要做一件事：下面「待补清单」里，把公司口径写成可执行的标准（公式、模板、对照表、默认值）。实习生按标准填，不要每人一套英文。

东迪 5514894P11 只是例句，不是下一份的答案。

---

## 先看结论

60 格分成三类：

| 类型 | 格数 | 实习生怎么做 | 要不要运营另写标准 |
| --- | --- | --- | --- |
| A. 公司固定设置 | 12 | 照账号默认勾，不要改 | 不用。变了由负责人改一处即可 |
| B. 跟单勾选 | 20 | 看这一单采购，用已有判断句勾 | 不用另写文案。判断句已在训练页/FAQ |
| C. 要补内容标准 | 28 | 必须按公司模板/对照表来写或选 | **要。本文后半就是清单** |

价格、日历、提交审核不算「内容」，不进 C。口径是：后台真实价照抄，不要把客人网页零售价填进去；训练页不要点真后台 Submit。

---

## A. 公司固定设置（12）

整号或整条门票线通用。换产品也不改，除非负责人通知。

| 后台这一格 | 现在的默认 | 谁在用 |
| --- | --- | --- |
| 创建方式 Creation type | 手填 Manual Creation | 门票训练 / 日常新建 |
| 智能生成 Smart Creator | 跳过 | 同上 |
| 撰写语言 Input language | English | 对客英文 |
| 翻译方式 Translation mode | Use automated translation (recommended) | 没有专人译文时 |
| 经销身份 Reseller status | Independent reseller | 账号口径 |
| 对客电话 Phone number | HK +852 3428 8182 | 账号口径 |
| 币种 Product currency | HKD | 账号后台币种 |
| 预订通知邮件 Notification email | 勾上 Yes | 账号口径 |
| Tripadvisor listing | Reotrip Tokyo / Shinjuku, Tokyo | 账号商家页 |
| 公司 Logo | 公司文件，不要私人图 | 账号 |
| 票面预览 Ticket preview | 训练页只示意 | 非上架文案 |
| 提交审核 Submit for review | 训练页禁用；真后台才提交 | 流程，不是内容 |

改这些 = 改账号政策，不要让实习生按产品发挥。

---

## B. 跟单勾选（20）

每单可能不同，但选项是现成的，训练页已有判断句。不需要再写「怎么写英文」。

默认按门票线；采购不一样再改。

| 后台这一格 | 门票默认 | 什么时候改 |
| --- | --- | --- |
| 产品大类 Product type | Ticket or pass | 这单实际是团、接送、包车时（会整套模块跑偏，先问负责人） |
| 行程类型 Itinerary type | Ticket/pass | 不是票券时 |
| 有没有接送 Hotel pickup | No, travelers go directly to the location | 采购含车 / 可选接送 |
| 多个景点 Multiple attractions | No | 真的是多园/多馆联票。地铁通票不是第二个景点 |
| 真人导游 Live guide | No | 采购含导游 |
| 语音导览 Audio guide | No | 采购含语音 |
| 书面导览 Written guide | No | 采购含书面导览 |
| 导游语言 Guide languages | 空 | 上面有导游才勾 |
| 快速通关 Skip the line | No | 采购明确含免排队，且包含项也要写上 |
| 额外费用确认 Extra-cost | 不把园内另购写成已含 | 有现场必付再写入包含/不包含 |
| 健康限制 Health restrictions | 不选 | 官方/采购有健康限制 |
| 难度 Difficulty | Most travelers can participate | 明显高强度行程 |
| 计价方式 Price type | Per person 按人 | 按车/按团的产品（本线一般不是） |
| 取消政策 Cancellation | All sales final（不能退） | 采购可退时先问负责人，不要自己改成免费取消 |
| 恶劣天气 Bad weather | 不勾 | 门票通常不因天气自动退 |
| 人数不足 Not enough travelers | 不勾 | 门票不是跟团 |
| 确认方式 Confirmation | Instant confirmation（库存已对接） | 要人工确认 / 库存未对接 |
| 截止类型 Cut-off type | Relative to start time | 一般不动 |
| 供应商价 Supplier prices | 抄后台真实价 | 不是写文案。禁止填客人页 starting-from |
| 价格表 Price matrix | 每档每天都要有价 | 新上架不要学现网漏价；不是写文案 |

## C. 要补内容标准（28）

这些格要么要**写英文**，要么要**从对照表里选**，要么**口径现在互相打架**。没有公司标准，实习生会照抄东迪或每人一套。

下面每条都写清：

- 现在训练页有什么口径（草稿，供拍板）
- 请运营补什么
- 建议产出物（公式 / 模板 / 对照表 / 默认值）

拍板后把结论填回各条「请补」下面即可。

---

### C1. 标题怎么写

**格：** Product title（必填）

**现在的草稿口径：** 景点名 + Ticket + Optional 加项。有加购才写 Optional。无车不要写 Transfer。不要中文、不要堆折扣词。

**东迪例句（仅此产品）：** Tokyo Disneyland Ticket & Optional Tokyo Subway Pass

**请补：**

1. 门票标题是否统一用这条公式？有无字数上限？
2. 主票是「一日票 / 快速通票 / 兑换券」时，标题里必须出现哪些词？
3. 哪些词禁止出现（折扣、Klook、中文、Transfer）？
4. 两个加项怎么写（& Optional A & B，还是只写主加项）？

建议产出：标题公式 1 张 + 禁止词列表。

---

### C2. 内部参考码

**格：** Product reference code（选填）  
**状态：待负责人。现网未展示。**

**现在的草稿口径：** 填采购 SKU / 内部编码。没有就空着，不要编。

**请补：**

1. 要不要填？填采购 SKU、Bókun、还是内部产品码？
2. 格式样例（前缀、是否含 option 码 TG6/TG7）？
3. 没有码时：空着，还是用某一套规则生成？

建议产出：填/不填规则 + 格式样例 3 个。

---

### C3. 票种细类怎么选

**格：** Ticket / pass type

**现在的草稿口径：** 乐园门票选 Theme Park。不要普通景点也一律勾 Theme Park。

**东迪例句：** Theme Park

**请补：** 对照表，至少覆盖：

| 实际卖什么 | 选哪一项 |
| --- | --- |
| 乐园门票 | ？ |
| 普通景点入场 | ？ |
| 交通/城市通票 | ？ |
| 免排队票 | ？ |
| 乐园+交通 combo | 跟主票还是跟加项？ |

建议产出：一张对照表。

---

### C4. 主题怎么选（主题池）

**格：** Themes，最多 3 个

**现在的草稿口径：** 先选类目，再勾该类目下主题。要和景点真实属性相关，不要刷曝光。训练页写「先问有没有门票主题池」。

**东迪例句：** 类目 Time of Day → Day、Sunset、Night  
（这份像权宜之选，不像门票主题池。）

**请补：**

1. 门票线指定主题池（类目 + 可选主题，最多 3 个怎么排优先级）
2. 乐园 / 观光景点 / 交通通票各用哪几个
3. 明确禁止：为曝光勾无关主题

建议产出：门票主题池 1 张。

---

### C5. 封面和相册

**格：** Cover photo、Photo gallery

**现在的草稿口径：** 一眼认出景点；去水印、去别家品牌、无价格字/二维码；横图优先。现网 Photos +7。训练页图是前台公开图，**不能当后台封面标准**。

**请补：**

1. 封面必须满足什么（主体、横竖、分辨率、能否有人、能否有文字）
2. 相册几张、顺序（封面 → 景点 → 内部 → 不要地图价目）
3. 图从哪来（官方 / 采购 / 公司图库），谁有权用
4. 禁止清单（别家 logo、价格、二维码、截图）

建议产出：图片规范 1 页（可配对/错各 1 张）。

---

### C6. 集合地址怎么写

**格：** Meeting point / attraction location

**现在的草稿口径：** 无接送填景点官方英文名 + 完整地址，不要只写城市，不要填酒店。

**东迪例句：** Tokyo Disneyland, 1-1 Maihama, Maihama, Urayasu 279-0031 Chiba Prefecture

**请补：**

1. 固定格式是否为：`官方英文名, 街道, 城市 邮编 都道府县/州`
2. 地址以谁为准（景点官网 / Google / 采购）
3. 无接送时，这一格能不能写车站名

建议产出：地址格式一句 + 来源优先级。

---

### C7. 落客、接送补充说明（无车标准句）

**格：** Drop-off、Additional pickup details

**现在的草稿口径：**

- 落客：无车则活动在集合点结束
- 补充：写清 No hotel pick-up or private transfer included；可加附近有公共交通；不要列酒店接送区

**东迪例句：**

- Drop-off: This activity ends back at the meeting point.
- 补充: No hotel pick-up or private transfer included. Public transportation options are available nearby.

**请补：**

1. 无车产品是否固定用上面两句（或公司指定英文）
2. 有可选接送时，补充说明必须写哪些（区域、等候、未接如何处理）
3. 禁止写什么（没车却列酒店列表）

建议产出：无车标准句 2 句；有车模板 1 段。

---

### C8. 景点官方名称

**格：** Attraction / POI

**现在的草稿口径：** 主票对应的官方英文名，不要昵称。地铁不是景点。

**东迪例句：** Tokyo Disneyland

**请补：**

1. 名称以谁为准（Viator 景点库 / 官网英文 / 采购）
2. 东京迪士尼乐园 vs 迪士尼海洋、大小写、要不要写 Park
3. 联票两个园怎么填（若 B 类已规定「多个景点=Yes」，这里怎么写主 POI）

建议产出：命名来源 + 常见景点标准英文名表（可先从高频票开始）。

---

### C9. Duration 口径（必须先拍板）

**格：** Duration  
**现在两套说法不一致，不能让实习生猜。**

| 来源 | 说法 |
| --- | --- |
| 已上线后台（东迪） | Total Duration **10 hours**（客人通常待多久） |
| 训练页「上架前先问自己」 | 一日票可以填 **1 day**（票能用多久） |

**请补，三选一或写清分工：**

1. 这一格**只填通常待多久**（hours）。票面有效期写到标题 / 包含项 / 须知。一日票常见 8–10 hours，以谁的数为准？
2. 这一格**只填票面有效期**（1 day / 2 days）。那东迪现网 10 hours 还跟不跟？
3. 分产品类型：乐园填 hours，博物馆通票填 days？

**在标准落地前，按已上线后台：这一格不是票面有效期。**

建议产出：1 条死规定 + 3 个示例（一日乐园 / 两日票 / 兑换后 N 天有效）。

---

### C10. 景点说明怎么写

**格：** Attraction description  
**状态：训练页暂估**（现句来自分销页，后台原文可能不同）

**现在的草稿口径：** 2–4 句英文：景点是什么 + 票含入园。不写核销步骤、不写交通攻略、不堆促销。

**请补：**

1. 是否锁定「2–4 句」和句序（是什么 → 含什么 → 不含交通/核销）
2. 能不能摘官网。有无禁止形容词表
3. 要不要公司审稿

建议产出：句序模板 + 合格/不合格各 1 段。

---

### C11. 包含项怎么写

**格：** What's included

**现在的草稿口径：** 一条一项。先写两档都有的；只某套餐才有的加括号，写明套餐名。不要按最贵档写满。现网产品级没写括号，**训练页用括号当示范**。

**东迪例句：**

- 1-day Tokyo Disneyland pass
- 24-hour unlimited Tokyo Metro & Toei Subway Pass (only if the Ticket and Tokyo Subway Pass option is selected)

**请补：**

1. 括号英文是否统一：`(only if the XXX option is selected)`
2. 主票怎么写（1-day pass / admission ticket / e-ticket）必须含有效期吗
3. 现网没括号、训练页有括号——上架以谁为准
4. 一条里禁写什么（形容词、折扣、核销长文）

建议产出：包含项模板（人人都有 / 加购才有）+ 公司是否强制括号。

---

### C12. 不包含项怎么写

**格：** What's excluded

**现在的草稿口径：** 一条一项，专有名词留英文。有地铁通票时写明不含 JR / 山手线 / 其他私铁。没有地铁加项不要抄东迪这几条。不要只写 Personal expenses。

**东迪例句：** JR Lines (including Yamanote line) ticket；Other private railways；Other personal expenses

**请补：**

1. 门票是否永远要有一条 Other personal expenses
2. 交通加项时，不含线路的写法模板
3. 接送、餐饮、快速通关未包含时，是否必须各写一条

建议产出：门票「不含」底表 + 交通加项追加句。

---

### C13. 卖点长文怎么写

**格：** Main sales description（独特之处）

**现在的草稿口径：** 先写履约风险，再写套餐，再写不含接送。不要只堆形容词。

**东迪现网开头：**

1. IMPORTANT ENTRY POLICY
2. VOUCHER IS NOT A TICKET
3. 出行前 7 天发 Official E-Tickets

**请补：**

1. 凭证不能入园的产品，是否**必须**用固定英文段（请给标准段，允许替换「7 天」等数字）
2. 凭证能直接入园的产品，禁止出现 Voucher is not a ticket
3. 后半卖点是否要条目化（含什么 / 加项 / 无接送）
4. 字数、禁止词（梦幻、必玩、最优惠）

建议产出：两种模板（凭证不能进 / 凭证能进）各 1 份。

---

### C14. 无障碍怎么写

**格：** Accessibility

**现在的草稿口径：** 有就据实写，没有的限制不要编。东迪现网混了：轮椅不便、靠近公共交通、婴儿坐腿上。

**请补：**

1. 门票默认允许勾哪些（例如一律可靠近公共交通）
2. 轮椅、婴儿车以谁为准（景点官网）
3. 「婴儿坐腿上」放无障碍还是放须知/年龄——指定一处，不要三处各写一次还不一致

建议产出：默认选项 + 来源。

---

### C15. 出行须知 / 限制怎么写

**格：** Additional information

**现在的草稿口径：** 一条一条列。写清是整份产品限制还是某一档。国籍/居住地限制：没有就不要抄东迪日籍那条。

**东迪关键两条：**

- Need to exchange a physical subway ticket at major stations of the Tokyo Metro and Toei Subway.
- This offer is not available for Japanese passport holders（整份、所有套餐）

**请补：**

1. 国籍/居住地限制的标准英文句（整产品 vs 某一档）
2. 适用人群以采购为准的确认流程（谁签字）
3. 须知和核销打架时听谁的（见 C19，东迪地铁「换实体票」vs「闸机扫官方 QR」）
4. 婴儿坐腿、适合所有体能，是不是须知固定底表

建议产出：须知底表 + 限制句模板 + 「和核销冲突时听谁」。

---

### C16. 年龄档怎么对齐

**格：** Age groups

**现在的草稿口径：** 必须能出票，对齐该景点/供应商官方票种，不要套东迪或欧美习惯。Infant 若只在须知写坐腿、没有单独价，就不要开婴儿档。

**东迪例句：** Adults 18–99；Youth 12–17；Children 4–11。Infant 未挂价。

**请补：**

1. 官方票种表以谁为准（乐园官网 / 采购合同 / 出票系统）
2. Adult/Youth/Child 的命名能不能改，还是后台有固定档名只能改岁数
3. 3 岁以下、老人票、学生票没有采购时能不能开档

建议产出：对齐流程 3 步 + 「禁止套用东迪年龄」一句。

---

### C17. 儿童随行、每单人数上限

**格：** Child accompaniment rule、Max travelers per booking

**现在的草稿口径：** 儿童规则按景点官方。东迪：Infants must sit on laps。每单上限现网 15。

**请补：**

1. 15 是不是公司门票默认上限？采购另有上限时谁改
2. 婴儿/儿童陪同的标准英文是否统一
3. 必须大人陪同的产品，岁数怎么写进这一格

建议产出：默认上限数字 + 陪同句 1～2 条。

---

### C18. 套餐档命名和说明

**格：** Product options

**现在的草稿口径：** 名称要看出差别，禁止 Option 1。名称必须和包含项一致。

**东迪例句：**

- Ticket and Tokyo Subway Pass (TG7)
- Ticket Only (No Subway Pass) (TG6)

**请补：**

1. 命名公式（主票 + and 加项 / Ticket Only (No XXX)）
2. 内部码 TG6 要不要写进客人看得到的名称
3. 每档说明最低写什么（含什么、不含接送、有效期）
4. 几个档才拆 option，什么情况做成加购而不是第二档

建议产出：命名公式 + 说明最低字段。

---

### C19. 核销说明 + 凭证是不是入园票（必须先拍板）

**格：** Separate entry ticket?、Special ticket redemption instructions

这是客人投诉最高的两格，且东迪内部已有两套口径。

**现在的草稿口径：**

- 平台凭证不能进 → 必须选「另发官方票」
- 核销英文：先写凭证不能扫，再分段写每种票。禁止只写 Show this voucher at the gate

**东迪后台核销结构：**

- STOP: THIS VOUCHER IS NOT YOUR ENTRY TICKET
- 乐园：官方 QR 入园；出行前约 7 天发电票
- 地铁：Metro / Toei 闸机扫官方 QR，首次进站起算 24 小时，不含 JR

**须知里另有一句：** 到主要车站换实体地铁票。  
**两处不完全一致。**

**请补：**

1. 凭证不能进的产品：是否强制固定开头段（请给英文，数字做成可替换）
