# 项目说明：HBX 中国大陆酒店产品信息爬取

## 1. 背景

业务需要从 **Bedsonline / HBX 中国区**（`app-bedsonline.gta-travel.cn`）系统化获取 **中国大陆酒店** 产品信息，规模约 **41 万** 量级。  
本仓库历史工作区主要覆盖 **活动（Activities）** 提取；酒店为新业务线，独立落在 `hotel-cn-crawl/`。

## 2. 目标

| 目标 | 说明 |
|------|------|
| 覆盖范围 | 中国大陆酒店（市场 mkt=CN） |
| 内容语言 | 尽量同时保留中文与英文字段/接口响应 |
| 价格 | 酒店日历价（按入住日窗口滚动） |
| 存储 | 外接盘 `/Volumes/CodexArchive/hbx-hotel-crawl`，分批目录 |
| 运行方式 | Grok / 脚本控制 **本机 Google Chrome**；必要时用浏览器已存密码登录 |
| 可靠性 | 磁盘温度与空间定期监控；爬取可断点续跑 |

## 3. 非目标（当前阶段）

- 不一次全量 41 万无断点硬爬（先试点城市再铺开）
- 不改写历史 `workspaces/` 活动提取产物
- 不依赖 mark 设备上缺失的 `bedsonline-extract` skill（本项目自包含）

## 4. 架构

```text
┌──────────────────┐     CDP :9222 / launch      ┌─────────────────────┐
│  scripts/*.mjs   │ ──────────────────────────► │  Google Chrome      │
│  lib/chrome.mjs  │     intercept XHR/fetch      │  Bedsonline SPA     │
└────────┬─────────┘ ◄────────────────────────── └──────────┬──────────┘
         │  darwinToken + hotel APIs                        │
         ▼                                                  │
┌──────────────────┐                                        │
│  local data/     │   mirror batches                       │
│  artifacts/      │ ──────────────────────► /Volumes/      │
└──────────────────┘     CodexArchive/hbx-hotel-crawl       │
                                                            │
┌──────────────────┐                                        │
│ disk monitor     │ smartctl temp + df + write probe       │
│ launchd 30min    │ ──────────────────────► monitor/*.json │
└──────────────────┘
```

### 4.1 登录判定

真正可用的条件：

1. 浏览器能打开 `main?mkt=CN`
2. `localStorage.darwinToken` 存在
3. 酒店相关 API 返回 200 且含业务数据（非 401）

“页面在 main”或仅有部分 cookie **不够**。

### 4.2 数据落盘约定

```text
batches/CN/by-city/<城市或destinationCode>/<runId>/
  hotels.jsonl          # 一行一酒店（基础+内容）
  calendar.jsonl        # 一行一房价窗口
  api-capture.json      # 原始 API 抽样（调试期）
  meta.json             # 批次元信息

state/
  checkpoint.json       # 城市进度、偏移、失败列表
  *-plan.json           # dry-run / 运行计划
```

中英文字段：同一 `hotelCode` 合并；不要用中文名字符串做主键匹配。

## 5. 关键依赖

- macOS + 本机 Google Chrome
- Node.js ≥ 18 + Playwright（chrome channel）
- 外接盘 `CodexArchive`（WD_BLACK SN850X 4TB，APFS）
- `smartctl`（已用于温度：约 39°C 正常区间）

## 6. 风险与注意

| 风险 | 缓解 |
|------|------|
| 登录 401 / 密码变更 | 调试 Chrome 手动登录；用已存密码；更新环境变量 |
| 41 万全量耗时长 | 按城市分片、批大小可配、checkpoint |
| 接口限流 | `requestDelayMs`、失败退避、夜间跑 |
| 磁盘过热/写满 | `monitor-external-disk.sh` + launchd；alerts |
| 字段不稳定 | 先 `probe-hotel-ui` 固化 API 映射再批量 |
