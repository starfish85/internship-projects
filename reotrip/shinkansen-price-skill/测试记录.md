# 测试记录

测试时间：2026-07-23
测试渠道：Klook 日本铁路公开查价页面
测试样例数量：8 个文本样例，另列 3 类截图场景

## 已验证内容

- 文本和图片输入入口可用。
- 可识别日期、出发地、目的地、成人和儿童人数。
- 出发地固定映射到页面左侧，目的地映射到页面右侧。
- 日期支持日历月份切换，并在点击后验证页面日期。
- 单一时间会先匹配页面区间，再按车次真实出发时间细筛；时间不限时选择全部区间。
- 已展开车次不会重复点击。
- HTML 导出包含时间、车站、车次、坐席类别和真实展示价格。

## 已知问题

- 当前只稳定支持 Klook，Trip.com 未完成自动操作。
- 未开售日期的参考日期选择仍需人工确认，不能自动保证任务说明中的完整两个月规则。
- 不同 Klook 页面版本的 DOM 结构可能变化，需要在页面改版后重新验证车次展开和价格读取。
- 当前未做完整的 8 个样例逐条联网回归；交付前应按样例覆盖东京、大阪、京都、金泽及返程路线。

## 价格检查

价格只读取网站真实展示内容，不做汇率换算。若页面未提供 USD 或 HKD，结果会保留页面币种并给出提示。
