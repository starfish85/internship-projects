# 新干线车票价格查询浏览器插件使用说明

## 1. 插件用途

本插件用于在 Klook 日本铁路查询页面中，根据文字或图片需求自动提取查询条件，填写出发地、目的地、日期和出发时间，筛选车次，展开符合条件的车次并读取页面实际显示的座席价格，最后导出为 HTML 文件。

插件只进行公开查询和信息读取，不会登录账号、下单、锁票、填写乘客信息或进入支付流程。

## 2. 交付文件

解压交付压缩包后，主要内容如下：

```text
shinkansen-price-skill/
├─ browser-extension/       可加载到 Chrome/Edge 的扩展文件夹
├─ examples/                输入、输出和测试案例
├─ 使用说明.md              本文档
├─ README.md                项目概览
├─ SKILL.md                 任务约束和执行规则
├─ 交付说明.md              交付范围说明
└─ 测试记录.md              测试记录
```

## 3. 安装方式

1. 使用 Chrome 或 Edge 打开扩展管理页面：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择交付文件中的 `browser-extension` 文件夹，不要选择外层项目文件夹。
5. 打开 Klook 日本铁路查询页面，例如：
   `https://www.klook.com/en-US/rails-32/1012-japan/search/`
6. 如果刚刚重新加载了扩展，刷新一次 Klook 页面，使页面重新加载插件脚本。

## 4. 输入格式

可以直接输入文字，也可以上传包含需求文字的图片。推荐一条需求中尽量同时写明以下字段：

```text
日期 + 出发地 + 目的地 + 出发时间 + 成人数量 + 儿童数量
```

字段之间可以用逗号、空格、换行或自然语言连接。以下写法均可识别：

| 字段 | 推荐格式 | 说明 |
| --- | --- | --- |
| 日期 | `2026年8月20日`、`2026-08-20`、`8月20日` | 未写年份时按运行时本机当前年份补全；当前示例年份为 2026 |
| 出发地 | `从东京站`、`出发地：东京站`、`Tokyo Station` | 城市名会映射到 Klook 可选的新干线站点 |
| 目的地 | `到京都`、`目的地：京都`、`Kyoto` | 出发地和目的地按左右位置分别填写 |
| 明确时间 | `上午10点`、`10:00`、`12点30分` | 会识别到具体小时和分钟，不会只保留“上午”等时段 |
| 约略时间 | `12点左右`、`12:00前后` | 先选择包含该时间的页面时间区间，再按车次实际出发时间细筛 |
| 时段 | `上午`、`下午`、`晚上` | 按对应时间范围筛选 |
| 不限时间 | `时间不限`、`全天`、`没有特别要求` | 四个出发时间区间全部选择 |
| 成人 | `2位成人`、`2大`、`成人2人` | 成人数量单独保留 |
| 儿童 | `1位儿童`、`1小`、`儿童1人` | 儿童数量单独保留，不与成人合并 |

### 人数规则

必须尽量分别写成人和儿童数量。例如：

```text
2大1小
2位成人，1位儿童
成人2人，儿童1人
```

插件会显示为 `Adults: 2` 和 `Children: 1`。不能只写成“3个人”来代替“2大1小”，因为成人票和儿童票价格可能不同。

### 未指定时间的规则

没有明确出发时间时，插件不会擅自选择某一个小时，而是将出发时间识别为“全天”，在 Klook 页面中选择全部四个时间段。只写“12点”或“12:00”时，会先选择包含 12 点的区间，再按车次的实际出发时间继续筛选。

### 关键词推测规则

如果没有具体日期或时间，但需求包含季节关键词，插件会生成参考日期和参考时段，便于继续查询：

| 关键词 | 参考日期 | 参考出发时段 |
| --- | --- | --- |
| 樱花季 / Sakura | 3月30日 | 08:00-10:59 |
| 红叶季 / 枫叶 | 11月20日 | 08:00-10:59 |
| 暑假 / Summer vacation | 8月1日 | 全天 |
| 黄金周 / Golden Week | 5月3日 | 全天 |

这类日期和时间是查询用的推测值，不代表真实开放日期或保证有票，结果中会标注推测说明，应在查询前确认。

## 5. 完整操作流程

1. 在 Klook 页面打开插件弹窗。
2. 在 `Text requirement` 中输入文字，或通过 `Choose image` 上传截图。
3. 点击 `Extract fields`，检查 `Parsed fields` 中的出发地、目的地、日期、时间、成人和儿童数量。
4. 插件先把出发地填入页面左侧的出发地框，把目的地填入右侧的目的地框，并分别选择对应站点。
5. 选完目的地后打开出发日期日历。插件会点击右上角月份箭头切换到目标月份，再点击目标日期，并验证页面显示的日期是否与识别日期一致。
6. 按识别的出发时间选择时间区间。时间不限时四个区间都选；有具体时间时，再根据车次实际出发时间细筛。
7. 所有条件填写并筛选完成后，点击页面上的 `Search`。必须在这一步之后等待结果页刷新，不能提前读取车次。
8. 在结果页中逐个点击所有符合条件车次右侧的橙色下拉箭头。已经展开并读取过的车次会跳过，避免重复点击导致页面重新收起。
9. 点击 `Export train HTML`，导出当前已读取的车次详细信息。插件也可能在自动流程完成后自动生成一次 HTML 文件。
10. 如果流程卡住，可以点击弹窗中的 `Reload extension`，然后刷新 Klook 页面，再从当前查询条件重新执行。

## 6. HTML 输出内容

导出的 HTML 只保留影响出行和比价的关键信息：

- 出发日期
- 出发时间和到达时间
- 出发站和到达站
- 列车名称或车次
- 自由座席
- 指定座席普通车厢
- 指定座席绿色车厢
- 页面实际显示的价格、库存或座席备注
- 成人和儿童人数上下文

同一车次中重复出现的同一种座席类型会合并；不同座席类型会分别展示。价格直接复制网页显示内容，不做汇率换算。

## 7. 完整参考示例

将下面文字直接粘贴到输入框即可：

```text
客人一家2大1小，计划2026年8月20日上午10点左右从东京站到京都，请查询可预订的新干线车次和不同座席价格。
```

预期识别结果：

```text
出发地：东京站
目的地：京都
出发日期：2026-08-20
出发时间：10:00
成人：2
儿童：1
```

再例如，未指定时间时：

```text
2位成人和1位儿童，2026年9月15日从京都到东京，时间没有特别要求，请查询新干线价格。
```

预期识别结果中的出发时间为：

```text
全天，四个时间区间全部选择
```

## 8. 常见问题

**没有点击日期或页面没有跳转怎么办？**

确认出发地、目的地、日期和出发时间都已完成，再点击 Klook 页面上的 `Search`。日期和筛选条件完成后，网站通常要通过 `Search` 才会加载对应日期的车次。

**为什么没有价格？**

确认已经进入搜索结果页，并且符合条件的车次右侧橙色箭头已展开。价格只从展开区域读取；若网页本身没有公开显示价格，HTML 会保留说明，不会虚构或估算价格。

**为什么只显示一种座席？**

确认车次已经完全展开并等待座席区域加载。插件会分别读取页面出现的座席类型；如果网页只返回一种可售座席，就只输出这一种。

**上传图片没有识别结果怎么办？**

使用清晰、正向、文字对比度较高的截图，确保日期、路线、时间和人数在图片中完整可见。上传后先看到图片预览，再点击 `Extract fields`。

**结果是否可以直接购票？**

不可以。本插件只用于公开查询和导出信息，最终价格、库存和可预订状态以 Klook 页面实时显示为准。
