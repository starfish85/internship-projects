# 使用说明文档

## 打开页面

打开文件：

```text
outputs/three-panel-page.html
```

页面为本地静态 HTML，不需要安装依赖，不需要启动服务。

## 页面结构

页面分为三栏：

- 左侧：订单信息
- 中间：缺失字段
- 右侧：英文邮件生成与复制

窄屏显示时，页面会保留横向三栏布局，可以横向滚动查看。

## 选择日期

左侧顶部有日期下拉框。

选择日期后，页面会刷新：

- 订单列表
- 订单数
- 已确认数
- 待补充数
- 当前订单缺失字段
- 邮件生成对象

## 筛选订单

左侧顶部有三个统计卡片：

- `订单数`：显示当前日期全部订单。
- `已确认`：显示当前日期已确认订单。
- `待补充`：显示当前日期存在缺失字段的订单。

点击任意统计卡片后，订单列表会自动滚动到顶部。

## 数据来源筛选

从 ReoTrip 系统读取订单前，应先在 ReoTrip 订单列表中筛选 `接送订单`。

推荐流程：

1. 打开 ReoTrip 订单列表。
2. 在 ReoTrip 页面中筛选 `接送订单`。
3. 确认浏览器地址栏 URL 已经包含筛选条件。
4. 再读取筛选后的链接。
5. 将筛选结果导入本地工具。

这样导入后的订单默认都是接送订单，页面会按接送订单规则检查缺失字段。

如果筛选结果中混入无法确认类型的订单，应标记为：

```text
需人工确认 / Manual review required
```

## 查看订单信息

左侧订单卡片展示运营处理时最常用的信息。

接送订单会显示：

- 订单号
- 客人
- 类型
- 产品
- 套餐
- 接送时间
- 上车地址
- 下车地址
- 人数

金额和供应商不在左侧卡片中展示，避免列表过长。

## 查看订单详情

点击左侧任意订单卡片，会弹出订单详情窗口。

弹窗中展示更完整的订单信息，包括：

- 订单号
- 订单状态
- 客人
- 订单类型
- 产品
- 套餐
- 出行日期
- 出行/接送时间
- 人数
- 金额
- 供应商
- 缺失字段
- 上车点
- 下车点
- 酒店英文全名
- 酒店地址
- 行李数量
- 行李尺寸
- 行李类型
- 航班/列车/船名

空字段会显示为 `未填写`。

关闭弹窗的方法：

- 点击 `关闭`
- 点击弹窗外的背景区域
- 按键盘 `Esc`

## 查看缺失字段

中间栏根据当前选中的订单自动计算缺失字段。

缺失字段来自订单信息和订单类型规则，不是固定写死的展示。

订单中已经存在的信息不会出现在缺失字段中。

无法判断订单类型时，会标记：

```text
需人工确认 / Manual review required
```

## 接送订单缺失规则

接送订单重点检查：

- 出行日期 / Travel date
- 接送时间 / Pickup time
- 上车地址 / Pickup location
- 下车地址 / Drop-off location
- 酒店英文全名和具体地址 / Hotel full English name and full address
- 人数 / Passenger count
- 行李配置 / Luggage details
- 航班 / 列车 / 船名编号 / Flight, train, or ferry number/name

规则说明：

- 订单已有日期但缺少时间时，只询问具体接送时间。
- 酒店只有中文名、简称或模糊地址时，仍视为不完整。
- 接送线路需要明确上车点和下车点。
- 行李配置至少包含数量、尺寸和类型。
- 交通枢纽相关订单必须收集对应航班、列车或船名编号。
- 码头订单重点检查接送时间、酒店英文名和地址、接送线路、船名、行李配置。
- 码头订单中，如果 `pickup` 已经是完整酒店地址，不再要求酒店地址。
- 码头订单中，如果 `flight` 或备注里已有船名，不再要求船名。

## 生成英文邮件

选择订单后，点击右侧：

```text
邮件生成
```

页面会生成一封英文询问邮件。

邮件特点：

- 语气礼貌、简洁、清晰。
- 只询问当前缺失的信息。
- 不重复询问订单中已经存在的信息。
- 包含订单号，方便客户识别。

## 复制邮件内容

生成邮件后，点击：

```text
复制邮件内容
```

即可复制右侧邮件内容，方便粘贴到邮件或客服系统中发送。

## 注意事项

- 不要在页面或文档中保存 API Key、账号密码、Cookie、Token、私人令牌。
- 不要把 Gitee 私人令牌发给他人或截图。
- 本项目只用于本地读取和整理订单信息。
- 不要用该项目修改 ReoTrip 线上订单。
- 不确定的信息应保留为缺失字段或人工确认，不要猜测。
