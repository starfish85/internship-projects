# Tokyo Ticket Availability Collector

Source repository for the Tokyo Studio Tour ticket availability scraper, notes, and delivery docs.

## Layout
- `03_实习生提交/wb_tokyo_ticket_availability.py` main scraper
- `03_实习生提交/wb_tokyo_ticket_availability_v1.py` earlier version
- `03_实习生提交/README.md` usage notes
- `03_实习生提交/交付说明.md` delivery summary
- `03_实习生提交/采集过程记录.md` collection log

Generated outputs, browser caches, zip archives, and local debug artifacts are ignored from version control.
