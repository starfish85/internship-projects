# 实习项目合集

ReoTrip 一期实习作品。每个子目录是一个独立项目，进入对应文件夹看该项目的 README 即可运行。

Python 练手项目已迁到个人项目仓库：https://github.com/starfish85/personal-projects

原先用「一个分支一个项目」，已经整理成目录，默认分支为 `main`。

## ReoTrip 实习

| 目录 | 项目 | 说明 |
| --- | --- | --- |
| [reotrip/order-missing-fields](reotrip/order-missing-fields) | 订单缺失字段助手 | 静态页面展示接送订单、识别缺失字段、生成英文补件邮件 |
| [reotrip/shinkansen-price-skill](reotrip/shinkansen-price-skill) | 新干线查价插件 | 从文字/截图提取行程，在 Klook 公开页读取可售车次和价格 |
| [reotrip/shinkansen-delivery-pack](reotrip/shinkansen-delivery-pack) | 新干线 Skill 交付包 | 同一任务的正式提交材料（任务说明、过程记录、提交目录） |
| [reotrip/tokyo-ticket-collector](reotrip/tokyo-ticket-collector) | 东京影城门票采集 | 只读采集 Warner Bros. Studio Tour Tokyo 可售日期和时段 |
| [reotrip/nol-listing-toolkit](reotrip/nol-listing-toolkit) | NOL 上架工具包 | 门票/接送上架 Skills + 后台韩→简体翻译插件 |
| [reotrip/nol-listing-automation](reotrip/nol-listing-automation) | NOL 上架自动化脚本 | Chrome CDP 填写合作后台草稿；含成田/关西机场填表脚本 |
| [reotrip/nol-world-crawler](reotrip/nol-world-crawler) | NOL World C 端爬虫 | 公开页竞品调研，判断京沪是否有可售单门票 |
| [reotrip/nol-japan-transfer-audit](reotrip/nol-japan-transfer-audit) | 日本接送上架审计 | 2026-08-17 日本接送草稿审计交付 |

| [reotrip/ru-zh-translation-ext](reotrip/ru-zh-translation-ext) | 俄语站翻译插件 | Sputnik8 / Tripster 俄译中浏览器扩展，方便运营看俄语产品页 |

| [reotrip/viator-product-crawl](reotrip/viator-product-crawl) | Viator 已启用产品采集 | 拉已启用产品、匹配门票供应链、整理 Excel/飞书 |
| [reotrip/hbx-hotel-crawl](reotrip/hbx-hotel-crawl) | HBX 酒店产品爬取 | Bedsonline 中国区酒店信息提取脚本（不含爬取数据） |
| [reotrip/ticket-check-notes](reotrip/ticket-check-notes) | 门票核对资料 | 德国门票核实记录、Tripster 接送票表 |
